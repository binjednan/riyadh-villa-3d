# فيلا الرياض ثلاثية الأبعاد

نموذج HTML الأصلي المصدر من Claude، مع تحديث الأثاث والستائر بطلب مهند.

## تحديث التنسيق الداخلي
- ستائر شفافة موجية وستائر جانبية بدرجات كتان دافئة، وطبقة عرض مستقلة.
- جلسات بتنجيد فاتح ووسائد زيتونية وقواعد خشبية، وأطراف مستديرة.
- أسرّة برؤوس منجدة، وطاولات بدرجات الحجر والخشب، وسجاد متعدد الحواف.
- بيانات المخطط والفتحات وتوزيع قطع الأثاث الأصلية لم تتغير. التفاصيل الداخلية مقترحات عرض وليست مواصفات شراء أو تنفيذ.

## مراجع الاستلهام
- [Minotti Connery](https://www.minotti.com/en/connery): الجمع بين التنجيد والتفاصيل الخشبية/المعدنية والكتل الهندسية اللينة، دون نسخ منتج بعينه.
- [Silent Gliss Wave](https://www.silentglissglobal.com/englb/fabrics/fabric-expertise/wave/): انتظام الطيات الموجية.

## التحقق
تم فحص تركيب JavaScript، ومطابقة بيانات النموذج المضمّنة للأصل، وتشغيل النسخة المحلية في Chrome على الماك. ظهر المجسم والأثاث والستائر، وعُزل الأرضي والأول، واختُبرت طبقة الستائر إخفاءً وإظهارًا. لم يُختبر على الآيفون، ولا يعني ذلك اعتماد مقاسات أو مواد تنفيذية.

إضاءة «قراءة الداخل» وسيلة عرض محايدة، وليست محاكاة إضاءة أو حساب لوكس. أما مواضع وأبعاد الشرائح فهي اقتراح خاص بهذا النموذج؛ المصدر يدعم المبدأ ولا يعتمد تصميم الفيلا. يلزم فحص فتح النوافذ والتنظيف والهروب وأحمال الرياح والارتداد من الاستشاري قبل التنفيذ.

### الاستخدام
- «مسقط»: إسقاط متوازٍ، السحب للتحريك والقرص/العجلة للتقريب. «أرضي / أول / سطح» للتبديل.
- «العرض»: المناظير، جودة العرض، الإضاءة التوضيحية، تصدير الصورة والمناظير المحفوظة.
- «الغرف»: بحث بالاسم، ثم الضغط على النتيجة للتركيز عليها وقراءة بياناتها.
- «التعديلات»: إظهار/إخفاء مقترح التظليل الجديد وباقي المقترحات الأصلية.
- «اللوحة»: إخفاء اللوحة لإعطاء النموذج مساحة أكبر، ثم إظهارها مجددًا.
- عند تركيز لوحة الرسم: الأسهم للتحريك/التدوير، `+` و`-` للتقريب، و`F` للملاءمة.

### حدود هذا التحديث
بيانات المخطط الأصلية المضمّنة لم تتغير. لا يوجد اعتماد لتوزيع أو مادة تنفيذية جديدة. تبويب الكود وادعاءات المطابقة موروثة من النموذج الأصلي، وليست تدقيقًا قانونيًا أو هندسيًا جديدًا؛ أضيف تنبيه واضح داخل العارض. لم تُضف محاكاة طاقة أو نسب وفر أو مقاسات مشتريات. لم يُستبدل العارض بتطبيق جديد.

## تحديث الإظهار الواقعي واللمس — ١٢ نوفمبر ٢٠٢٦

### ما طُبّق
- أسماء الغرف أصغر: ٩ بكسل افتراضيًا، ويمكن اختيار ٨–١٤ بكسل من «العرض». زر مباشر أعلى المجسم يخفيها ويظهرها، مع حفظ التفضيل على الجهاز.
- إصبعان يتحركان معًا لسحب العرض، وإبعادهما يقرب وتقريبهما يبعد، في المنظور والمسقط. لا يتحول انتهاء القرص إلى اختيار غرفة بالخطأ. يمكن متابعة حركة الإصبع الباقي بعد رفع الآخر.
- خامات PBR، اختلاف خشونة الحجر والخشب والقماش، نسيج إجرائي بمقياس ثابت، بيئة انعكاس PMREM، إخراج sRGB وضبط تعريض ACES الخاص بإصدار Three.js r128.
- تفاصيل إطارات داخل حدود الفتحات القائمة، ظلال تماس تقريبية أسفل الأثاث، وأشجار أقل هندسية مع إبقاء مواضعها الأصلية. يمكن إيقاف تفاصيل الإظهار، أو إخفاء طبقتها.
- إضاءة النموذج الشمسية التقريبية، وضوء ذهبي أو ناعم فنيان، مع تحكم في السطوع. الإضاءتان الفنيتان لا تمثلان ساعة أو موقعًا حقيقيًا.
- «لقطة نظيفة» تخفي التسميات والحواف واللوحة. تبقى أزرار إعادتها متاحة. تصدير PNG يحترم إخفاء الأسماء وحجمها.
- ملاءمة أولية للفيلا عند فتح الصفحة على شاشة هاتف، وجودة خفيفة توقف الظلال.

### المقترحات الجديدة مستقلة
- «رمل وحجر»: لوحة ألوان وخامات رملية مع هندسة معالجة «معاصر دافئ» نفسها، للمقارنة دون تغيير المخطط.
- «حديقة حصوية على جانبي المدخل»: طبقة تعديل منفصلة، متوقفة افتراضيًا، تضيف شريطين وأحواضًا مقترحة دون تحريك الأشجار أو إغلاق الممر.
- أفكار إضافية داخل تبويب «التعديلات»: استمرار الحجر، خصوصية الفتحات، ترك وسط الفناء مفتوحًا، تقليل النجيلة وتوحيد الخشب والقماش.
- «كتلة المخطط فقط» توقف إضافات الواجهات وكل مقترحات التعديل. لا تحذف أي مقترح أو تغير بيانات النموذج.

[البحث والمراجع والتوصيات](RESEARCH_REALISM.md) يميز بين مبادئ المصادر والاختيارات التصميمية لهذا المودل. الموقع المقصود مدينة الرياض في أبوظبي؛ لا تغيير لاتجاه الشمال أو افتراض اعتماد المقاسات. تفاصيل المواد والإطارات والأحواض مقترحات إظهار وليست وثائق تنفيذ. الخامات والسماء إجرائية، وليست مواد ممسوحة أو صورة موقع أو HDRI ملتقطًا. لا يدّعي هذا التحديث تصويرًا فوتوغرافيًا أو محاكاة إضاءة أو طاقة معتمدة.

### تشغيل اختبارات التطوير

الموقع المنشور ما زال ملف HTML ذاتيًا ولا يحتاج تثبيت حزم. الاختبارات وحدها تستخدم Node.js وlinkedom:

```sh
npm ci
npm test
```

الاختبارات تتحقق من تركيب السكربتات، وثبات SHA256 لنص بيانات المخطط، ورياضيات اللمس وحالات الواجهة. فحص DOM يستخدم بديلًا لمحرك الرسم ولا يثبت جودة WebGL أو أداء الجهاز. تفاصيل الفحص البصري وحدوده في [سجل التحقق](VERIFICATION.md).
